# SIBO (Sobrecrecimiento Bacteriano del Intestino Delgado)

## Protocolo en 5 fases (@RyanJAyala, 13 ago 2026)

El orden importa: **matar primero y vuelve a crecer**.

1. **Barrera** → [[Zinc]] carnosina + [[Glutamina|L-glutamina]]
   - Reparar la pared intestinal primero
2. **Biofilm** → [[NAC]] + serrapeptasa
   - Disolver la matriz protectora de las bacterias
3. **Starve** → dieta baja en FODMAP, eliminar el picoteo (grazing)
   - Dejar de alimentar a las bacterias
4. **Kill** → [[Orégano|aceite de orégano]] + [[Berberina]]
   - Solo cuando la barrera está reparada y el biofilm disuelto
5. **Sweep** → [[Jengibre]] + caminata de 15 min después de las comidas
   - Estimular el complejo motor migratorio (MMC) para barrer los restos
