
# [[Ejercicios]]

·Usa un bol o recipiente grande agua fría con hielo extra; sumerge toda la cara aguantando la respiración tanto como puedas. Puede hacerse tanto a primera como última hora. Extra: puedes hacer sonar el sonido MMMM mientras tienes la cara sumergida para mayor efecto.

Este ejercicio ayuda a tener mejor tolerancia al frío, para prepararte para la [[Ducha fría]]. 

También activa el [[Nervio vago]].
